# robots-fog-mini-sim + Mobile Phone

**Схема:** датчик → fog-узел → курьер → **мобильный телефон** (приёмник результата).
Смотри `system_diagram.png`.

## Как это работает (простыми словами)
1) Датчик собирает «сырые» данные.
2) Fog-узел их чистит/усредняет (чтобы меньше тянуть в сеть).
3) Курьер доставляет итоговое сообщение.
4) Телефон принимает сообщения и кладёт их в буфер, пользователь смотрит результаты.

## Что запускать
- `viz_phone_pipeline.py` — строит:
  - график сквозной задержки «до телефона» (мс) для каждой задачи;
  - график размера буфера телефона;
  - печатает среднюю задержку (одно число — метрика).

Запуск:
```
python viz_phone_pipeline.py
```

## Идеи для экспериментов
- Ускорить fog (уменьшить его диапазон задержек) и посмотреть, как меняется средняя задержка.
- Поменять `read_interval_ms` у телефона: если читать реже — буфер растёт.
